# Мой помощник (harness)

Это твоя маленькая программа для работы с кодом: ты пишешь задачу простыми словами в окне браузера, а помощник читает файлы в отдельной папке `workspace`, меняет их и показывает, что получилось. Если результат не нравится — нажимаешь кнопку «Откатить».

Терминал использовать не нужно.

## Как запустить (один раз)

**Windows:** дважды кликни `start.bat`.
**Mac / Linux:** дважды кликни `start.command` (если система не даёт запустить — открой файл через «Открыть с помощью > Терминал»).

Откроется браузер с адресом `http://localhost:8787`. Появится чёрное окно — это нормально, просто сверни его. Когда захочешь выключить программу — закрой это чёрное окно.

> Если браузер не открылся сам, открой `http://localhost:8787` вручную.

## Как настроить HydraAI

1. У тебя есть ключ вида `sk-hydra-ai-...` из [дашборда HydraAI](https://dashboard.hydraai.ru).
2. В левой панели окна вставь ключ в поле **«Ключ HydraAI»**.
3. Нажми **«Сохранить»**. Ключ запомнится в этом браузере и никуда не будет записан в файлы проекта.
4. Нажми **«Обновить список»**, чтобы подгрузить доступные модели. По умолчанию выбрана `gidra-code-auto` — она хорошо подходит для кода.
5. Напиши задачу внизу и нажми «Отправить» (или Enter).

Примеры задач, которые можно написать:
- «Создай файл calculator.py с функцией сложения»
- «Прочитай README.txt и объясни, что там написано»
- «Добавь тест для моей функции»

Если ключа пока нет — поставь галочку **«Демо-режим (без ключа)»**. Помощник создаст пример файла в `workspace`, и ты сможешь попробовать кнопку отката. Чтобы работать с HydraAI, сними галочку и вставь ключ.

## Что видно на экране

- **Слева** — настройки, список чатов и файлы папки `workspace` (по клику файл открывается).
- **В середине** — переписка. Помощник показывает, какие действия он выполняет.
- **Справа** — список изменённых файлов и кнопка «Откатить последние изменения».

Откат возвращает и файлы, и сам разговор к состоянию перед задачей. Кнопка отката работает с последней задачей.

## Важно знать

- Помощник работает **только в папке `workspace`** — вне её файлы не меняются.
- Инструмент `bash` умеет запускать простые команды проверки. Если результат не понравится — нажми откат.
- Ключ хранится в браузере. Если откроешь программу в другом браузере — ключ придётся вставить снова.
- Счёт за запросы идёт на балансе HydraAI; модель `hydra-gpt-mini` дешевле, `gidra-code-auto` удобнее для кода.

# Для разработчика

`harness-core` — TypeScript-ядро: провайдеры, агентный цикл, инструменты, сессии, чекпоинты. Веб-окно — тонкий слой поверх него.

## Структура

```
src/
  types.ts             общие типы и контракт событий
  utils.ts             id, токены, валидация, безопасные пути
  providers/           sse, anthropic, openai-совместимый, registry
  session/             session, file store, checkpoint, compaction
  tools/               read / write / bash
  agent/               loop.ts (низкий уровень), agent.ts (фасад)
  server/              локальный веб-сервер и SSE-API
web/                   интерфейс (HTML/CSS/JS без сборки)
workspace/             папка-песочница агента
examples/              демо без ключей и пример с реальной моделью
tests/                 node:test + tsx
```

## API ядра

```ts
import { Agent } from 'harness-core';

const agent = new Agent({
  model: { provider: 'hydra', model: 'gidra-code-auto' },
  provider: openaiCompatibleProvider({
    apiKey: process.env.HYDRA_API_KEY,
    baseURL: 'https://api.hydraai.ru/v1',
  }),
  cwd: './workspace',
});

for await (const event of agent.stream('Создай файл')) {
  // text_delta, tool_start, tool_end, checkpoint, done, error…
}
```

`run(prompt)` возвращает итог; `Session` сохраняется в `.harness/sessions/*.json`; `rollbackToCheckpoint()` откатывает файлы и сообщения.
