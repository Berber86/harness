# Мой собственный ИИ-помощник для кода (Coding Harness)

Эта программа — твой личный мини-аналог **Arena.ai** (режима агента), который запускается прямо у тебя на компьютере.

---

## Как это работает (простыми словами)

Представь, что у ИИ есть **мозг** и **руки**:
1. **Мозг** — это нейросеть (Claude, ChatGPT, Gemini или локальная модель). Она сама не умеет нажимать кнопки или открывать файлы, она только умеет думать и писать текст.
2. **Руки** — это инструменты в файле `harness/tools.py`:
   - `read_file` — прочитать файл;
   - `write_file` — создать или перезаписать файл;
   - `edit_file` — аккуратно заменить кусочек текста в файле;
   - `bash` — выполнить команду в терминале (как будто ты сам ввёл её в командной строке).
3. **Связующее звено (Harness)** — это `harness/agent.py`. Он передаёт твой вопрос нейросети. Если нейросеть говорит: *«Мне нужно посмотреть файл `app.py`»*, программа сама читает файл и отдаёт результат обратно нейросети. Так происходит по кругу, пока задача не будет решена.
4. **Окно чата** — это `app.py` на базе **Chainlit**. Он рисует красивый чат в браузере, где видно и ответы ИИ, и каждый его шаг.

---

## Из каких файлов состоит проект

- `app.py` — запускает веб-чат в браузере.
- `harness/agent.py` — главный цикл общения с нейросетью.
- `harness/tools.py` — «руки» агента (работа с файлами и терминалом).
- `harness/prompts.py` — главная инструкция для нейросети (кто она и в какой папке работает).
- `.env.example` — шаблон для твоих секретных API-ключей.
- `pyproject.toml` — список библиотек, которые нужны программе для работы.

## Как запустить с нуля (пошагово)

### Шаг 1. Открой терминал в папке проекта
Убедись, что ты находишься внутри папки `harness`.

### Шаг 2. Создай виртуальное окружение и установи библиотеки
Введи эти команды по очереди:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
```
*(На Windows вместо `source .venv/bin/activate` используй `.venv\Scripts\activate`)*

### Шаг 3. Настрой API-ключ
Скопируй шаблон настроек в рабочий файл `.env`:
```bash
cp .env.example .env
```
Открой файл `.env` в любом текстовом редакторе и вставь свой ключ от нейросети (например, `ANTHROPIC_API_KEY=...` или `OPENAI_API_KEY=...`).

### Шаг 4. Запусти программу
```bash
chainlit run app.py -w
```
После этого в терминале появится ссылка (обычно `http://localhost:8000`). Открой её в браузере — перед тобой появится чат!

## Что можно написать агенту для проверки
- *«Посмотри, какие файлы есть в этой папке, и объясни, что они делают»*
- *«Создай простой файл `hello.py`, который выводит текущую дату, и запусти его»*
- *«Найди ошибки в моём коде»*
